# AI 屏幕助手(Android)

## 运行
1. 安装 Android Studio(Koala 或更新),File → Open 选本文件夹,等 Gradle 同步完成。
2. 手机开启开发者模式和 USB 调试,点 Run;或 Build → Build APK(s) 打包安装。
3. 打开 App:
   - 设置:填接口地址、令牌、模型名(令牌只保存在手机本地,代码里没有)
   - 角色:新建/编辑 AI 人设
   - 启动:授权悬浮窗、麦克风、录屏,然后切到任意 App 使用悬浮球

## 注意
- 语音识别用系统自带 SpeechRecognizer。很多国产系统没有,会提示“本机没有语音识别服务”,
  此时需要安装 Google 语音服务,或把识别换成 Vosk / 云端识别。
- 悬浮窗里的“屏幕”是你说话时发送的最新一帧;“屏幕变化时主动评论”默认关闭,开启会持续消耗额度。
- 横竖屏切换后需要重新开启一次助手。

## 遮挡框
悬浮面板 →“新建遮挡框”。长按拖动、拖右下角 ◢ 缩放、点一下删除。框内区域会在发给 AI 前被涂黑。
